# 🗂 База знаний для ИИ-ассистента turbinist.ru

Здесь хранится информация, собранная со страниц сайта turbinist.ru.
ИИ-ассистент использует эти файлы, чтобы отвечать на вопросы пользователей.

## 📁 Структура

```
knowledge_base/
├── README.md              ← этот файл
├── map.md                 ← карта сайта (что собрано, что нет)
├── access/                ← тарифы доступа, оплата, контакты
│   ├── tariffs.md         ← все цены и тарифы
│   ├── how-to-buy.md      ← инструкция по оплате
│   └── contacts.md        ← контакты администратора
├── advertise/             ← цены на рекламу (будет)
├── turbine/               ← газовые турбины (будет)
└── encyclopaedia/         ← энциклопедия (будет)
```

## 📄 Формат файлов

- Все файлы — Markdown (.md)
- В начале каждого — источник (URL) и дата сбора
- Данные только из публичных страниц сайта
- Никаких выдумок — только то, что реально есть на сайте

## 🔄 Обновление

База собирается вручную или скриптом. При добавлении новых материалов на сайт — файлы пересобираются.
