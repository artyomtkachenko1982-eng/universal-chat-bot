🧠 Обоснование дизайна

🎯 Принцип «Архив ≠ Удаление» Человек боится потерять данные. Архив — это «сундук», куда чат уходит, но не пропадает. Психологически легче нажать «Закрыть», зная что можно открыть заново.
🛡 Защита от дурака (2 шага) Критические действия (удаление) — с подтверждением. «Закрыть» — 1 клик. «Удалить» — 2 клика + предупреждение. Fitts Law: опасные кнопки дальше и глубже.
🔮 Расширяемость Список чатов легко примет и «Чат с юзером» — просто новый элемент. Фильтры (Все/Активные/Архив) работают для любого количества чатов. Поиск сверху — для десятков чатов.
🧘 Спокойствие пользователя Если чат закрыть случайно — не страшно, он в архиве. Кнопка восстановления — рядом. Удаление — только через меню → подтверждение. Пользователь чувствует контроль.
🧹 Борьба со спамом Мусорные чаты можно удалить навсегда. Кнопка «Удалить» — в меню, красным цветом, с подтверждением. Никаких «очистить историю» — только полное удаление.
📋 План реализации (шаги)
  1. Шаг 1: Перенести чат из renderInputArea в messages area (JSX), сделав список чатов и открытый чат
  2. Шаг 2: В renderInputArea оставить только поле ввода + кнопка отправки (для открытого чата)
  3. Шаг 3: Добавить закрытие чата (архив) + восстановление
  4. Шаг 4: Добавить удаление чата (с подтверждением)
  5. Шаг 5: Сделать фильтры (Все/Активные/Архив)
