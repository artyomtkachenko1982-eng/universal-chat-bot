# Правила для Aider в проекте Universal Chat Bot

## Язык и стиль
- Пиши код на русском (комментарии, сообщения коммитов, readme)
- Объяснения только на русском, кратко и понятно новичку

## Безопасность
- НЕ трогай .env файлы
- НЕ выводи токены и пароли в диалоге
- НЕ трогай bridge/api-bot-bridge.php (уже залито на turbinist.ru)

## Где что лежит
- Весь код бота: /app/
- Мостик DLE: /bridge/
- Виджет чата: /app/widgets/chat/index.html
- Конфиг: /app/core/config.py

## Git
- После каждого изменения делай git commit
- Сообщения коммитов на русском

## Docker
- После правки Python-файлов: docker restart uc_app
- После правки requirements.txt: docker compose up -d --build
